# Problem Solving with TypeScript & OOP

## About This Project

This project is an assignment focused on problem-solving using TypeScript and Object-Oriented Programming (OOP).

The main goal of this assignment is to practice TypeScript fundamentals, functions, generics, interfaces, classes, inheritance, and asynchronous programming.

## Technologies Used

- TypeScript
- Object-Oriented Programming (OOP)
- Promises and Async Programming

## Problems Covered

1. Default Parameters
2. Union Types and Type Narrowing
3. Readonly Tuples
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generics and Keyof Constraints
7. Classes, Inheritance, and Access Modifiers
8. Promises and Asynchronous Programming
